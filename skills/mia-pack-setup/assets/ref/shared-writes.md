# Write and draft rules

Read this before any draft, or any change to a CRM, calendar or file.

## Changes
Get approval before changing a CRM or calendar. Show a table with field, current value, new value and evidence. Apply only what was approved, read the records again, then report what saved. Work in batches of ten, one batch at a time. Never merge, delete or change owners.

## Drafts
Draft emails only; never send. A value never seen (name, link, address, price) gets a visible placeholder such as [link], and one line above the draft says so.

## Pack files
A pack file holds no buyer names, companies, exact amounts or open-deal details. Aggregates over open deals (counts, shares, types) may enter.
