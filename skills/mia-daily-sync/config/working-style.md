# Working style

How one person runs their deals, so skills put the right work first and respect personal limits.

## Profile

Name, role, company, and whether this person sells, leads a team, or both. Skills read the role from here.

## Moves from my best deals

Moves repeated on the deals this person ran best, each with the kind of deal it came from. Skills protect these and suggest them for other deals.

## Time sinks

Work done often and late, seen in timestamps: notes entered days after a call, recaps that go out late or never, long research before meetings. Skills do this work first without being asked.

## Recurring slips

Moves from the best deals that most other deals never get. Skills check every deal for these and raise them early.

## Standing rules

Always and never rules: contact cadence, channels that are off limits, what is never sent in a first email.

## Tools in use

Connected tools, and tools used but not connected.
