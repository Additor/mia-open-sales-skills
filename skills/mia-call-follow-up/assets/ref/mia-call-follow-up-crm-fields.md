# Call follow-up: CRM change types

Read this when building the CRM update. Put forward a field solely if the call, or an email from today, clearly backs it up. If crm-guide.md exists, its field names, allowed values, and rules (Capture map, Required fields, Fields to ignore) outrank any other reading of the CRM; Proof by stage comes from deal-lifecycle.

| Change | Rule |
|---|---|
| Next step and its date | Always propose the step. Today's next step replaces the earlier one. Take its date from the call; a weekday-only date resolves per scoring-axes `## Definitions`. With no date said, omit the date and say so in one line; never guess one. |
| Stage | Suggest a move only if the call satisfies what Proof by stage requires for it, stating the reason briefly; if it does not, keep the stage as is. |
| Close date and amount | Only when the buyer gave a new timeline or number on the call. |
| Competitor named | Use the buyer's words. If the CRM has a competitor field with a pick list, match it to an allowed value exactly. |
| Qualification fields | Whatever the call answered among budget, decision maker, problem and timeline, or among the MEDDPICC, SPICED and BANT fields, written under the field names already in the CRM. |
| Follow-up tasks | One task per promise the user made, due on the date the call mentioned (weekday-only dates per scoring-axes `## Definitions`). With no date mentioned, omit the due date and say so in one line; never guess one. A rep's tasks list the rep as owner. |
| Call note | The summary from the layout, 3 to 5 lines: what happened, what changed, the next step. |
| New contacts | Propose only attendees missing from the CRM: name, title, email if known (an address never seen is a placeholder). People only mentioned on the call are not proposed; list them in one line "add when seen". Search the CRM first by email, then by name and company. If the person exists, suggest linking the record to the deal and do not create a duplicate. |

Anything the call does not support is left out. A blank field does less harm than a guess; move the unanswered question to "For the next meeting".
